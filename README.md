# sfc-gh-dfreriks.github.io

Index of public SAP + Snowflake demo applications: https://sfc-gh-dfreriks.github.io/

Rebuild: `python3 tools/build.py` (captures every live demo, then writes `index.html`); `--no-shots` reuses the screenshots. Add a demo by adding an entry to `DEMOS` in `tools/build.py`.
